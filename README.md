# Rakkit

Rakkit is a lightweight modder for Ultrapool. To get started, simply download the [latest release source zip](https://github.com/Multrapool/Rakkit/releases/latest) and extract the contents to your Ultrapool folder.

If Rakkit is installed correctly, your file structure should look something like this:
```
Ultrapool.exe
override.cfg
addons
godot
...
```
